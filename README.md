# ShadowVPN — Docs

Статический сайт с правовыми документами сервиса ShadowVPN.

## Структура

```
docs/
├── index.html       # Заглавная страница со ссылками
├── privacy.html     # Политика конфиденциальности (с пунктом про HWID)
├── terms.html       # Пользовательское соглашение
├── style.css        # Общие стили
├── script.js        # Курсор, анимации
└── CNAME            # Кастомный домен для GitHub Pages
```

## Деплой на GitHub Pages

1. Создай репозиторий, например `shadowvpn/docs` (или используй существующий).
2. Залей содержимое этой папки в корень репозитория (или в ветку `gh-pages`).
3. В настройках репо → **Settings → Pages**:
   - Source: `Deploy from a branch`
   - Branch: `main` (или `gh-pages`), folder `/ (root)`
4. В поле **Custom domain** введи `docs.shadowvpn.io` и поставь галочку **Enforce HTTPS**.
5. В DNS-провайдере домена `shadowvpn.io` пропиши CNAME-запись:
   ```
   docs   CNAME   <твой-username>.github.io
   ```
   (или A-записи на IP-адреса GitHub Pages — см. их доку).
6. Жди 5–30 минут на выпуск SSL-сертификата.

## Локальный просмотр

Просто открой `index.html` в браузере — никаких сборщиков не нужно. Шрифты подгружаются с Google Fonts.

## Что поправить перед публикацией

- В `privacy.html` и `terms.html` обнови **дату последней редакции** в блоке `.meta-row`, если будешь менять текст.
- Юрист по желанию проверит формулировки — текст написан в человеческом стиле, но не подменяет консультацию специалиста.
